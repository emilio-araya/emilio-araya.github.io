# Portafolio personal

Sitio personal y CV en línea: **https://emilio-araya.github.io**

Página estática sin build ni dependencias: HTML, CSS y JavaScript servidos directamente por
GitHub Pages desde la rama `main`.

## Contenido

| Archivo | Qué es |
|---|---|
| `index.html` | Portada: perfil, proyectos y contacto |
| `cv.html` | Currículum en formato web |
| `style.css` / `script.js` | Estilos e interacciones de la portada |
| `cv.css` / `cv.js` | Estilos e interacciones del CV |
| `certs/` | Certificados en PDF |

## Verlo en local

No necesita instalación. Cualquier servidor estático sirve:

```bash
python3 -m http.server 8000
```

Abrir `http://localhost:8000`.

## Publicación

GitHub Pages publica desde `main`. Un push a esa rama actualiza el sitio en un par de minutos.
